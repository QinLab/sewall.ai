A replayable research controller for public biological and environmental data. A model, a script or an MCP host proposes each step. One deterministic controller checks it, runs a bounded public Skill, and records every request and result in a hash-chained manifest that anyone can replay offline.

How a run works

Bounded Skills

Versioned Skills query NCBI, GenBank, Earth Engine, NOAA and USGS. Each declares its inputs, limits and what it may return. The planner sees small summaries.

Safe stop

A critical integrity finding quarantines the affected results and their descendants, stops dispatch, and the report reads STOPPED, NOT SUCCESSFUL.

Offline replay

sewall agent-replay re-derives saved results from recorded events. It repeats no model call and no source request.

Review after the run

A review forum, an FMEA-style release gate and a cross-run panel work on recorded manifests, each with a verify command. Records can be signed with Ed25519.

Any MCP host

The same controller is exposed as MCP tools, so commercial and open-weight models use one set of checks.

Expert consultation

sewall consult asks rule-based dataset experts and writes a capped plan script for the controller.

Expert agent domains

The implemented expert consultations use deterministic rules. A lab manager merges proposed Skill actions into a bounded plan; the controller checks and executes it. Experts propose actions, while scientists inspect and approve scientific interpretations.

NCBI dataset expert

Taxon names and synonyms, PubMed literature, GenBank inventories and BioProject metadata. Distinguishes transcriptome contigs from independent marker evidence.

Earth Engine expert

Sentinel-2 NDCI, named coastal regions and AlphaEarth context. Records scene caps, water masks, temporal limits and the inability of a chlorophyll proxy to identify a species.

Growth and community expert

Temperature, salinity, light, nutrients, grazing, competition and microbial interactions. Proposes literature, marker and ribotype Skills; it has not estimated or validated genotype-specific growth parameters.

EOL trait expert

Recognizes trait-data needs and provider-specific attribution. Currently records an explicit source gap; a live EOL/TraitBank connector is not implemented.

Methods and ecology reviewers

Challenge measurement quality, missing field observations, temporal comparisons and unsupported conclusions. Rule-based review is implemented; a bounded comparison also uses Gemini and Llama reviewers.

Planned domain coverage

NEON microbial ecology, Chesapeake Bay Program observations and published CBEFS forecasting knowledge are planned extensions. Their inclusion here does not imply custodian endorsement, operational adoption or implemented connectors.

Virtual discussion forum of the agentic research team

Researcher agents post evidence-linked questions, critiques, answers and concessions on a recorded run. A moderator checks the post structure and evidence references, preserves the discussion in a hash chain, and records open or contested concerns. A separate release gate can hold outputs despite an agent's favorable opinion. These are archived research discussions; this website does not run a live chat.

One run, four review conditions

October 16, 2026 comparison on the October 14 York River run
ConditionPosts kept / rejectedHeld outputs
No forum0 / 0All five NDCI months and the result
Rule-based methods and ecology11 / 0Result
Rules + Gemini methods + Llama ecology18 / 13August and September NDCI, plus result
Rules + adversarial Gemini reviewer13 / 0Result

Llama challenged the claimed rise in chlorophyll because the August and September ranges overlap. Gemini raised a cloud/glint quality concern. The model forum held those two months and the final result. An adversarial reviewer tried to clear a major concern without new evidence; the concern stayed contested.

This is one run with one model call per reviewer per round. Thirteen malformed model posts were rejected. The moderator checks whether evidence is new, but does not establish its semantic relevance. No condition validates a biological claim, and the comparison does not establish general multi-agent superiority.

Limits

  • No run establishes a biological finding. Results are public metadata and small summaries.
  • Abstracts and full text are not retrieved. Marker sequences are fetched only by fetch_markers, at most 100 public records per step.
  • Custodian federation and window alignment are not implemented.
  • Release-gate ratings are uncalibrated prototype settings.
